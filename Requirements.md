# Requirements

Here are the requirements and their implementation links.

1. Create a spring boot java api that does the following operations

   * Creates a new savings bank account.
     See: [SavingsAccountController](src/main/java/me/milstead/banking/controller/SavingsAccountController.java)
   * Gets the savings bank account
     See: [SavingsAccountController](src/main/java/me/milstead/banking/controller/SavingsAccountController.java)

2. Request Body needs to be validated
   See: [CreateSavingsAccountRequest DTO](src/main/java/me/milstead/banking/dto/CreateSavingsAccountRequest.java)
3. Account data model:
   See: [SavingsAccount JPA entity](src/main/java/me/milstead/banking/entity/SavingsAccount.java)
    * Account number (Autogenerated by the api)
    * Id (Autogenerated by the api)
    * Customer name (input : Mandatory)
    * Account nick name (input : optional)

4. Account Nick name should be between 5 to 30 characters.
   See: [CreateSavingsAccountRequest DTO](src/main/java/me/milstead/banking/dto/CreateSavingsAccountRequest.java)
   and
   [SavingsAccount JPA entity](src/main/java/me/milstead/banking/entity/SavingsAccount.java)

5. A customer cannot create more than 5 accounts.
   See [SavingsAccountService](src/main/java/me/milstead/banking/service/SavingsAccountService.java)
   for a naive, non thread safe implementation.
   A better implementation would require an additional customer table.
6. To ensure that the nick name is not offensive, the nick name should be checked against a list of offensive nick names.
   See [CensorService](me.milstead.banking.service.CensorService) along with some mocked 'offensive' words.
7. The bank account details needs to be saved in a postgres database, in a single table.
   See [Datasource and JPA config](src/main/resources/application.yaml).
   TODO: Could have used testcontainers (requires Docker) instead.
8. Optional:

    * Handle error scenarios where the database may be unavailable.
      TODO: Use circuit breaker pattern and Resilience4j to stop hammering DB
    * If you are familiar with a caching framework such as Redis, cache the GET calls to the postgres database.
      TODO: Not done, but could have used testcontainers (requires Docker) to provide a local Redis.
    * Write any tests that you think would be useful
      See [tests directory](src/test/java)

9. The application should be built using Gradle or Maven.
   See [build.gradle](build.gradle)
10. Please feel free to leave TODOs in the source where impractical or time consuming to code features that you would otherwise have coded in a real world api.
11. Where requirements appear to be insufficient, assume the requirements based on what you think might be best.
